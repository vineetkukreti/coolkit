## SECTION 1: MUSIC STRATEGY

### Music Arc Overview

The music follows a deliberate emotional journey across the video. It starts restrained and slightly tense during the problem hook, then opens up and builds confidence as the product is revealed, peaks in energy during the scraper demo (the technical showpiece), and closes with a resolved, confident finish at the CTA.

```
0:00 ─── Sparse/Tense ──── 0:15 ─── Hopeful Build ──── 0:50 ─── Energetic/Driving ──── 2:30 ─── Confident Resolve ──── 3:30
```

### Track Recommendations

#### Track 1 — Problem/Hook: 0:00 to 0:15
- **Mood:** Tense, slightly uncomfortable, relatable fatigue
- **Genre:** Dark lo-fi / minimal synth
- **Tempo:** 80 BPM
- **Key Instruments:** Sub bass pulse, sparse synth pad, very subtle hi-hat
- **Recommended Tracks:**
  - Pixabay: "Cyberpunk Background" or "Dark Minimal Techno"
  - Uppbeat: Search "dark minimal" — filter by Mood: Tense
  - YouTube Audio Library: "Density and Time" by Patrick Patrikios
- **Entry:** Fade in over 1 second from silence
- **Exit:** Hard cut (not fade) at 0:15 on logo reveal — the silence itself becomes a sound design moment

#### Track 2 — App Intro + Dashboard: 0:15 to 0:50
- **Mood:** Hopeful, clean, professional reveal
- **Genre:** Corporate electronic / indie lo-fi with forward motion
- **Tempo:** 110 BPM
- **Key Instruments:** Clean piano or muted guitar pluck, electronic percussion, light synth pad
- **Recommended Tracks:**
  - Epidemic Sound: "Positive Step" or tracks by Johan Glossner (tag: Corporate Indie)
  - Artlist: Search genre "Tech" + mood "Inspiring" — filter 100-120 BPM
  - Pixabay: "Corporate Motivation" by Frank Schroter
- **Entry:** Starts immediately after the logo reveal impact sound at 0:15, fades in over 0.5 seconds
- **Exit:** Crossfade into Track 3 at 0:50

#### Track 3 — Scraper Demo + Core Features: 0:50 to 2:30
- **Mood:** Driving, focused, technically impressive — the feeling of a machine working perfectly
- **Genre:** Dark electronic / modern synthwave / tech-hop
- **Tempo:** 125 BPM
- **Key Instruments:** Four-on-the-floor kick, synth arpeggios, driving bass line, filtered high-frequency textures
- **Recommended Tracks:**
  - Epidemic Sound: "Hacking the System" style tracks; search tag "Technology"
  - Artlist: "Neon Drive" or similar synthwave; Genre: Electronic, Mood: Focused
  - Uppbeat: Search "dark techno" or "hacker music"
  - Pixabay: "Technology Background" by Infraction
- **Entry:** Crossfade from Track 2 starting at 0:48, fully in by 0:50
- **Special:** At 1:10 (peak of terminal log scene), the track should be at full volume. This is the emotional apex.
- **Exit:** Begin fade-down at 2:20, transition to Track 4 at 2:30

#### Track 4 — CTA + Architecture Diagram: 2:30 to 3:30
- **Mood:** Confident, accomplished, forward-looking — "you've seen what it does, now act"
- **Genre:** Uplifting electronic / cinematic pop instrumental
- **Tempo:** 120 BPM (slightly slower than Track 3 to feel resolved, not rushed)
- **Key Instruments:** Full arrangement, clean drums, melodic synth lead, wide stereo pad
- **Recommended Tracks:**
  - Epidemic Sound: "Uplifting Corporate" category
  - Artlist: Genre "Cinematic", Mood "Triumphant", filter 115-125 BPM
  - YouTube Audio Library: "Inspired" by Kevin MacLeod (if YouTube distribution)
- **Entry:** Clean entrance at 3:00 after Settings section ends
- **Exit:** Fade out over 3 seconds ending at 3:30

## SECTION 4: MIXING SPECIFICATIONS

### Master Level Targets (LUFS / dBFS)

| Track Type | Target Level | Peak Limit |
|------------|-------------|------------|
| Voice Over | -16 LUFS / -6 dBFS peak | -3 dBFS |
| Background Music | -28 LUFS (under VO) | -12 dBFS |
| Music (no VO) | -20 LUFS | -6 dBFS |
| SFX (accents) | -12 dBFS peak | -6 dBFS |
| SFX (ambient loops) | -32 LUFS | -20 dBFS |
| Master Output | -14 LUFS (YouTube target) | -1 dBFS |

### Ducking Rules

Music ducking is triggered whenever VO is present. Use a sidechain compressor or manual automation:

- **Attack:** 50ms (fast enough to not clip VO onset)
- **Release:** 800ms (slow enough to not pump audibly)
- **Duck depth:** -8 dB from the music's current level
- **Exception:** During the `scrape_complete` (1:35) and `apply_success` (2:54) SFX moments, briefly release the duck by +3 dB even if VO is present — these are hero moments.

### Stereo Field Placement

| Element | Stereo Position | Notes |
|---------|----------------|-------|
| Voice Over | Center | Always dead center |
| Background Music | Full stereo | Natural spread |
| Terminal ambient | Slight left bias (L55/R45) | Feels like a monitor |
| UI clicks | Slight right bias (L40/R60) | Feels like on-screen right |
| Success SFX (scrape, apply) | Center | Needs full impact |
| Transition swooshes | Pan L → R (or R → L) | Match the visual transition direction |

## SECTION 6: FFMPEG IMPLEMENTATION COMMANDS

### Step 1 — Normalize All SFX to Consistent Levels

```bash
# Run on each SFX file to normalize
ffmpeg -i /path/to/sfx_raw/scrape_complete.wav \
  -af "loudnorm=I=-16:TP=-1.5:LRA=11" \
  /path/to/sfx_normalized/scrape_complete.wav
```

### Step 2 — Prepare Music Tracks with Fades

```bash
# Track 1: Fade in 1s, hard cut at 0:13 (13s total)
ffmpeg -i track1_dark_minimal.mp3 \
  -af "afade=t=in:st=0:d=1" \
  -t 13 track1_processed.wav

# Track 2: Fade in 0.5s, crossfade prep (0:16 to 0:50 = 34s)
ffmpeg -i track2_hopeful_electronic.mp3 \
  -af "afade=t=in:st=0:d=0.5,afade=t=out:st=32:d=2" \
  -t 34 track2_processed.wav

# Track 3: Long section with fade out at end (0:50 to 2:30 = 100s)
ffmpeg -i track3_driving_synthwave.mp3 \
  -af "afade=t=in:st=0:d=2,afade=t=out:st=96:d=4" \
  -t 100 track3_processed.wav

# Track 4: Final section fade out (3:00 to 3:30 = 30s)
ffmpeg -i track4_confident_uplift.mp3 \
  -af "afade=t=in:st=0:d=1,afade=t=out:st=27:d=3" \
  -t 30 track4_processed.wav
```

### Step 3 — Mix Voice + Music (with volume balance)

```bash
# Mix VO with ducked background music
# Music at 15% volume under VO (roughly -16dB)
ffmpeg -i voiceover_master.wav -i music_full_timeline.wav \
  -filter_complex \
  "[1:a]volume=0.15[music_ducked]; \
   [0:a][music_ducked]amix=inputs=2:duration=longest" \
  voice_music_mix.wav
```

### Step 4 — Apply Dynamic Ducking via Sidechain (Advanced)

```bash
# Sidechain compress music against VO
# VO triggers ducking on music track
ffmpeg -i voiceover_master.wav -i music_full_timeline.wav \
  -filter_complex \
  "[0:a]asplit=2[vo_out][vo_sidechain]; \
   [1:a][vo_sidechain]sidechaincompress=threshold=0.02:ratio=4:attack=50:release=800[music_ducked]; \
   [vo_out][music_ducked]amix=inputs=2:weights=1 0.4" \
  voice_music_sidechain_mix.wav
```

### Step 5 — Add SFX Layer

```bash
# Mix the SFX timeline (pre-assembled) with the voice+music mix
ffmpeg -i voice_music_sidechain_mix.wav -i sfx_timeline_master.wav \
  -filter_complex \
  "[1:a]volume=0.7[sfx]; \
   [0:a][sfx]amix=inputs=2:duration=longest" \
  full_audio_mix.wav
```

### Step 6 — Final Master with Loudness Normalization

```bash
# Normalize to YouTube target: -14 LUFS, -1 dBTP
ffmpeg -i full_audio_mix.wav \
  -af "loudnorm=I=-14:TP=-1.0:LRA=11:print_format=summary" \
  final_audio_master.wav
```

### Step 7 — Mux Final Audio with Video

```bash
# Replace video audio with final mastered audio
ffmpeg -i jobAutomate_demo_video.mp4 -i final_audio_master.wav \
  -c:v copy -c:a aac -b:a 192k \
  -map 0:v:0 -map 1:a:0 \
  jobAutomate_demo_FINAL.mp4
```
